# `data/eval` folder

This folder is for **evaluation and validation**: evaluation datasets, golden sets, experiment results, metrics, and artifacts used to measure quality for models, RAG, agents, or pipelines.

- **Main purpose**: centralize evaluation inputs and outputs so improvements stay measurable across project milestones.
- **Recommendation**: document each evaluation set (what it measures, how it was built, success criteria) and avoid sensitive data; use synthetic or anonymized data when needed.

> _Spanish version: [README.es.md](./README.es.md)._

## Regression model evaluation

Formal check of the Nexova monthly revenue forecast before any staging decision. It reuses the random forest, the causal features, the 8-year/2-year split, and `data/raw/nexova_sales.csv` from the forecast. Hyperparameters stay as they are.

`TimeSeriesSplit` builds five chronological folds on the training years only. The 2024–2025 block stays out. Each fold reports MAE and RMSE for the forest and for the seasonal baseline y(t−12). The chosen metric is the validation RMSE, as mean ± sample standard deviation. The learning curve and the written diagnosis are generated by:

```bash
uv run python scripts/evaluate_regression_model.py
uv run pytest tests/pipelines/test_temporal_cv.py
```

Outputs: `evaluation_report.md`, `learning_curve.png`, and `cv_stability.png` in this folder. The feature matrix is not stored. The script rebuilds it.
