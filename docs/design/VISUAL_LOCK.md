# Nexova Visual Lock — Oni Nocturne Oxblood

**Status:** LOCKED FOR 4g-006 IMPLEMENTATION  
**Date:** 2026-09-21

## Authority
The visual exploration produced 30 boards. For implementation, boards **26–30** are the normative lock; boards 01–25 are supporting references. The board archive remains an external design package; this repository stores the implementation contract distilled from it.

## Identity
**Oni Nocturne Oxblood** combines deep ceremonial darkness, traditional Japanese/irezumi visual language and highly restrained luxury. It must feel editorial and intentional — never gaming, tattoo-shop, kitsch or generic AI-SaaS.

## Palette
- Void black `#0A0A0A`
- Sumi `#1A1A1A`
- Charcoal `#2B2B2B`
- Bone `#EBE2D6`
- Oxblood `#8A0F14`
- Crimson `#B81E24`
- Antique gold `#B8985E`

## Motifs
Allowed as controlled accents: oni, peony, smoke/ink, torii, blood moon, lacquer/stone/washi/gold textures.

## Density split
- **Website:** immersive, editorial, cinematic, larger typographic scale and stronger art moments.
- **Backoffice:** calmer, denser and operational; ornamental imagery becomes watermark/context, not interface furniture.

## Rules
1. Red signals identity/action; it does not flood the UI.
2. Typography and negative space carry hierarchy before ornament.
3. One dominant visual motif per composition.
4. Art direction remains dark, tactile and material.
5. Accessibility, keyboard use and legibility override decoration.
6. Japanese influence is an art-direction language, not novelty ornament.
7. Public website copy may use only source-supported company claims.
8. Backoffice demonstration data must distinguish source baselines from live telemetry.
