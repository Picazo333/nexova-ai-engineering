# Independent Workflow Comparison Protocol

**Status:** APPROVED

## Purpose

The Nexova Premium Website plan and the workflow being developed in another ChatGPT conversation must remain **independent experiments** until both have produced their own complete proposal/result.

The external conversation is explicitly not a refinement branch of this plan. It is a competing attempt intended to test whether it can produce a materially better process or result.

## Independence rules

1. Do not reconcile the two proposals during design/execution.
2. Do not feed conclusions from one proposal back into the other while either is still being evaluated.
3. Shared project facts and user-approved brand truth are allowed; workflow-specific decisions are not.
4. Each proposal must define its own:
   - phases;
   - tool allocation;
   - budgets;
   - gates;
   - Definition of Done;
   - recovery strategy;
   - visual-quality strategy;
   - cost/complexity strategy.
5. Neither plan receives authority merely because it is newer or longer.
6. No hybrid implementation is created until the user explicitly asks to compare/reconcile.

## Comparison occurs only after independent completion

Comparison dimensions:
- final visual impact;
- brand fidelity;
- AI-slop resistance;
- implementation fidelity;
- responsive quality;
- motion quality;
- accessibility;
- performance;
- maintainability;
- number of tools;
- paid cost;
- inference/Figma/v0 consumption;
- human intervention;
- recoverability;
- evidence quality;
- repeatability for future client work.

## Outcome states

After both independent tracks are reviewed:
- PLAN_A_WINS
- PLAN_B_WINS
- DRAW_WITH_DIFFERENT_STRENGTHS
- HYBRID_JUSTIFIED

A hybrid is allowed only after independent evidence exists and must document exactly what is inherited from each track.

## Current rule

The approved Nexova plan proceeds on `design/oni-nocturne-premium-pass` without incorporating external-workflow recommendations unless the user later authorizes reconciliation.
